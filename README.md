# pizzeria-mamma-mia-hito-6
Deploy Sitio: https://pizzeria-mamma-mia-hito-6.onrender.com

## Descripción

En este Hito 6, el foco principal fue implementar Context API para manejar el carrito de compras de la aplicación.

Para lograrlo, se trabajó sobre la base del Hito 5 y se creó un contexto global para compartir la información del carrito entre distintas partes del sitio.

Ahora, al agregar pizzas desde el Home, el total del carrito se actualiza automáticamente en el Navbar. Además, en la página del carrito se pueden ver los productos agregados, aumentar o disminuir sus cantidades y revisar el total de la compra.

El sitio sigue conectado a la API de pizzas publicada anteriormente en Render.

Además, se dejó el Navbar fijo en la parte superior para poder ver el total del carrito mientras se navega por el sitio.
